# Workshop run sheet (3–4 hours)

## Goal

Every student leaves with a live Sepolia DApp for **one** of the 10 mini-projects and submission evidence for Exp 9 & 10.

Each project is a **standalone product** (`projects/0X-…/frontend`) with its own UI — students do **not** use a combined multi-app shell.

## Timeline

| Time | Block |
|------|-------|
| 0:00–0:20 | Kickoff + live demo of one finished DApp (e.g. CampusVote) |
| 0:20–1:00 | MetaMask + Sepolia + faucet + `cd projects/…/frontend && npm run dev` |
| 1:00–2:00 | Remix deploy chosen contract from that project folder |
| 2:00–3:00 | Connect that project's frontend, complete interactions |
| 3:00–3:30 | Screenshots / Etherscan / README line-by-line notes |
| 3:30–4:00 | Q&A, careers, optional Fabric mention |

## Room rules

1. One project folder per student/team (own frontend + own contract).
2. Each student deploys their own contract instance.
3. Pick **one** mini-project for the report.
4. Instructor holds spare Sepolia ETH.

## Mapping to lab index

- Exp 5–6: Remix + MetaMask + Sepolia deploy + frontend interaction
- Exp 9–10: Creating a blockchain application / DApp mini-project
- Exp 7–8: Hyperledger — case study homework, not this session
