# Workshop run sheet (3–4 hours)

## Goal

Every student leaves with a live Sepolia DApp for **one** of the 10 mini-projects and submission evidence for Exp 9 & 10.

## Timeline

| Time | Block |
|------|-------|
| 0:00–0:20 | Kickoff + live demo of one finished DApp |
| 0:20–1:00 | MetaMask + Sepolia + faucet + `npm run dev` |
| 1:00–2:00 | Remix deploy chosen contract |
| 2:00–3:00 | Connect frontend, complete interactions |
| 3:00–3:30 | Screenshots / Etherscan / line-by-line notes |
| 3:30–4:00 | Q&A, careers, optional Fabric mention |

## Room rules

1. Same frontend for everyone.
2. Each student deploys their own contract.
3. Pick **one** mini-project for the report (others stay in repo for exploration).
4. Instructor holds spare Sepolia ETH.

## Mapping to lab index

- Exp 5–6: Remix + MetaMask + Sepolia deploy + frontend interaction
- Exp 9–10: Creating a blockchain application / DApp mini-project
- Exp 7–8: Hyperledger — case study homework, not this session
